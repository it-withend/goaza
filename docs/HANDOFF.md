# Studyaza (goaza.xyz) — передача проекта второму разработчику

Дата: 14 ноября 2026. Ветка в работе: `claude/studyaza-university-atlas-59a13b`, продакшен деплоится из `main`.

## 1. Что это за продукт

Русскоязычный атлас вузов и грантов для абитуриентов, которые поступают за границу, в том числе из небогатых семей. Модель «знания открыты, инструменты — подписчикам»:

- **Открыто всем:** главная, карточки 1 000+ вузов (`/unis/[slug]`), гранты, гайды, сроки, анкета «Мой план» и личный кабинет.
- **Подписчикам Telegram-канала @studyaza:** полный каталог с фильтрами (`/dashboard`), финансовые детали вуза, гайд абитуриента (`/dashboard/guide`), полный подбор вузов и до 30 вузов в плане.

## 3. Как устроен сайт

### Страницы

| Путь | Что | Доступ |
|---|---|---|
| `/` | Лендинг-хаб: CTA «Составить мой план», превью кабинета, страны, гайды | все |
| `/plan/start` | Анкета из 6 шагов: имя и класс, бюджет, английский и оценки, SAT, страны, специальность | все |
| `/plan` | Личный кабинет: шанс поступить, корзины «Мечта / Реальные / Запасные», дедлайны, дела по неделям | все (noindex) |
| `/unis`, `/unis/[slug]` | Публичный каталог по странам и карточка вуза | все, индексируется |
| `/grants`, `/guides`, `/guides/[slug]`, `/deadlines` | Контент из `content/*.ts` | все |
| `/dashboard`, `/dashboard/u/[slug]` | Каталог с фильтрами и пресетами, полная карточка | подписчики |
| `/dashboard/guide` | Большой гайд абитуриента (стратегия, 103 merit-стипендии, CSS Waiver, эссе) | подписчики |
| `/podbor`, `/start` | Старые входные страницы, оставлены для совместимости ссылок | все |

Шапка одна на весь сайт: `components/site/SiteHeader.tsx`. Гостю она показывает пункты «Мой план · Вузы · Гайды · Гранты · Сроки». Подписчику — «Мой план · Каталог вузов · Гайд абитуриента · Гранты · Сроки», а также @username и «Выйти». `DashboardShell` рендерит её же.

### API

| Маршрут | Что делает | Защита |
|---|---|---|
| `POST /api/auth/telegram` | Проверяет HMAC подписи Telegram, свежесть `auth_date` (≤ 24 ч), членство в канале; ставит cookie `goaza_tg` | подпись Telegram |
| `DELETE /api/auth/telegram` | Выход (стирает cookie) | — |
| `GET /api/auth/status` | `{subscribed, username}` для шапки | — |
| `GET /api/universities` | Полные данные каталога | **401 без подписки** |
| `POST /api/podbor` | Подбор вузов по профилю. Гость получает счётчики и короткое превью, подписчик — весь список | частично |
| `POST /api/plan` | Шансы для вузов из «Моего плана». Гость — максимум 12 вузов, без закрытой суммы помощи (`aid_num`); подписчик — до 30 | частично |

### Данные и откуда они

1. **Supabase `universities`** — основная таблица. Её собрали из таблиц владельца (`D:\goo\goazaBD`), Common Data Set и сайтов вузов. Скрипты: `scripts/import_via_anon.cjs`, `scripts/etl/*`, `scripts/enrich_*.mjs`.
2. **Слой очистки `lib/university-clean.ts`.** Выполняется при каждом чтении. Он:
   - нормализует страны;
   - чинит имена и домены;
   - переводит цены в тысячах в доллары (`$57` → `$57,000`);
   - переносит дедлайны на цикл 2026/27;
   - склеивает дубли.
3. **Слой перевода `lib/humanize.ts`** превращает сырые значения в понятный русский:
   - английский: «6.5g» → «IELTS от 6.5 (≈ B2) или аналог»;
   - SAT: статусы и баллы из 1600;
   - эссе: «1 ps, 2 supp» → «Личное эссе + 2 дополнительных»;
   - тип вуза, виды помощи, need-blind и need-aware.

   Мусор (даты, ссылки, текст не из того поля) прячется.
4. **College Scorecard** (Министерство образования США). Скрипт `scripts/etl/scorecard.mts` скачивает цену после помощи по доходу семьи для избирательных вузов США и пишет `lib/scorecard.json`; данные есть у 383 вузов. Сопоставление идёт по уникальному домену, затем по названию (`lib/scorecard-match.ts`), разные кампусы одного домена не смешиваются.
5. **JSON в репозитории:**
   - `lib/university-enrichment.json`;
   - `lib/merit-scholarships-103.json` (103 merit-стипендии США);
   - `lib/us-css-aid-81.json` (81 вуз с CSS fee waiver);
   - `lib/logo-manifest.json` (логотипы в `public/`).
6. **Контент** (гайды, гранты, таймлайн) лежит в `content/*.ts`. Это факты, пересказанные своими словами; чужие тексты не копировать.

### Логика кабинета

- Профиль, список вузов и отмеченные дела хранятся в **localStorage браузера**: ключи `goaza_profile_v1`, `goaza_favs_v1`, `goaza_tasks_v1`. Работает хук `lib/use-applicant.ts`. Данные синхронизируются между вкладками, список ограничен 30 вузами. Каталог и кабинет пишут в один и тот же список.
- **Подбор** (`lib/matcher.ts`):
  1. Сначала бюджет.
  2. Затем жёсткий фильтр по английскому.
  3. Шанс считается от acceptance rate. Для need-aware вузов США он умножается на 0,5, для грантов вне США — на 0,35.
  4. Корзины: мечта < 15%, реальные < 45%, запасные ≥ 45%.
- **План** (`lib/plan.ts`):
  - «шанс хотя бы в один» вуз, ограничен 95%;
  - ближайший дедлайн;
  - дела: рекомендации за 42 дня до срока, эссе за 30, документы за 21, CSS Profile для грантов США.
- Если профиль уже есть, кнопки «Составить план» ведут в `/plan`, а не в анкету (`components/site/PlanCta.tsx`).

## 4. Безопасность и проверки

- `/api/universities` закрыт: без подписки отдаёт 401. Ответы помечены `Cache-Control: private, no-store`.
- Гостевой `/api/plan` ограничен 12 slug за запрос и не использует закрытую сумму помощи. Иначе её можно было бы вычислить, перебирая бюджет.
- Вход: подпись Telegram сверяется через HMAC-SHA256 токеном бота, `auth_date` не старше суток, членство в канале проверяется через Bot API `getChatMember`.
- Заголовки (`next.config`):
  - `X-Frame-Options: DENY`;
  - `frame-ancestors 'none'`;
  - `nosniff`;
  - `Referrer-Policy`;
  - `Permissions-Policy`.
- Middleware переводит все алиасы на goaza.xyz, иначе ломается домен Telegram-виджета.
- Входные данные API проверяются: slug — по регулярке `^[a-z0-9-]{1,160}$`, профиль — с ограничением диапазонов, localStorage — через `parseProfile` и `parseList`.
- В базе RLS только на чтение. Политики записи для anon не добавлять.
- **Тесты:** 121 тест в 23 файлах (`npm test`). Они покрывают:
  - подбор и план;
  - API и гейтинг;
  - кабинет и анкету;
  - шапку;
  - перевод полей;
  - контраст hover на жёлтых кнопках;
  - Scorecard;
  - очистку данных.
- **Перед каждым пушем:** `npm test`, `npx tsc --noEmit`, `npm run build` (prebuild заодно пересобирает `public/sitemap.xml`).

## 6. Известные проблемы и долги

- **Данные в базе грязные.**
  - В полях смешаны английский, сокращения и мусор: даты в поле «Язык», эссе в поле SAT, «IELTS 92 avg.», где на самом деле средний TOEFL. Сейчас это лечится при чтении (`humanize.ts`, `university-clean.ts`). Правильно — один раз нормализовать саму базу скриптом с `SUPABASE_SERVICE_ROLE_KEY`.
  - У 168 вузов США `tuition_num` хранится в тысячах (57 вместо 57 000). Страницы и подбор исправляются слоем очистки, но SQL-фильтр `tuitionMax` в `/api/universities` (`lib/universities.ts`, `applyFilters`) видит сырые числа.
  - Дубли: MIT ×4, Korea / South Korea. Часть дедлайнов 2026 года устарела. Фото кампусов местами не те.
  - `recommendations`, `app_fee`, `fee_waiver` пустые у всех строк.
- **План живёт только в браузере.** Если сменить устройство или почистить данные, он пропадёт. Нужна синхронизация с Telegram-аккаунтом (таблица профилей и запись через сервер с service-role ключом).
- **Мелочи из ревью:**
  - если список уже полон (30 вузов), «+ В план» молча ничего не делает;
  - ошибка анкеты не показывается;
  - подпись «с грантом» на плитке преувеличивает;
  - подсказка про SAT статичная;
  - у госпрограмм нет дат;
  - дни считаются по UTC;
  - список выполненных дел не чистится.
- В `components/dashboard/Dashboard.module.css` остались неиспользуемые стили старой тёмной шапки (`.topChrome`, `.topNav`, `.channelChip`) и свои цветовые токены `.shell`. Их стоит убрать и перейти на `--sz-*`.
